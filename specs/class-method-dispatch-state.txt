Phase 7: CLASS EXTENDS (inheritance)                             [COMPLETE]
  Branch: phase4-generic-decl (continues on same branch)
  - EXTENDS keyword for single inheritance: CLASS Child EXTENDS Parent
  - copy_struct_members() in sym.c: copies parent members into child, sets child->size = parent->size
  - Own members added after inherited members at correct offsets
  - Empty body allowed: CLASS X EXTENDS Y / END CLASS
  - Parent must be defined before child (no forward references)
  - Error code 97: "EXTENDS requires a defined CLASS type"
  - Class descriptors emitted in DATA section: _CLASSDESC_<NAME>: dc.l $hash, parent_ref
    - parent_ref = _CLASSDESC_<PARENT> if parent exists, else 0
  - Instance offset 0 now stores descriptor pointer (not hash directly)
  - declare_class(): writes #_CLASSDESC_<NAME> at offset 0 instead of #$hash
  - dispatch.s rewritten with three paths:
    - Single CLASS (N=1, bit 15=0): dereference descriptor, walk parent chain on miss
    - Single ATOM (N=1, bit 15=1): direct hash, no parent walk
    - Multi (N>1): convert CLASS descriptors to hashes in-place, exact match only
  - Destroys: d0-d3, a0-a2 (was d0-d3, a0-a1)
