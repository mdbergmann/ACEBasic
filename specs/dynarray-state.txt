## Notes

- INVOKE with return value: `x = INVOKE fun(args)` NOT `x = INVOKE(fun(args))`
- `fn` is a reserved word — don't use as variable name
- _DaCopyElement handles all type tags for Filter (avoids SINGLE conversion issues)
- Shellsort uses Knuth gap sequence (1, 4, 13, 40, 121, 364, 1093)
- Comparator receives raw LONGINT values + string pointers + type tags
