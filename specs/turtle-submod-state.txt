Phase 1: Create Turtle Submodule
---------------------------------
Status: COMPLETE
Branch: turtle-phase2-remove (combined with Phase 2 branch)
Commit: 8750227

Files created:
- [x] submods/turtle/turtle.b     - module source (14 public SUBs + 1 private helper, ~202 lines)
- [x] include/submods/turtle.h    - header with DECLARE SUBs and TG_RATIO_* constants
- [x] submods/turtle/test_turtle.b - test program (square, triangle, home, back, turnleft)

Build verified: YES (zero compiler errors)
Test verified:  YES (all shapes draw correctly, PASS in test-output.txt)

Features:
- Auto-detects pixel aspect ratio from screen dimensions in TgInit
- TgSetRatio allows manual override (useful for P96/RTG square-pixel screens)
- _TgMove private helper shared by TgForward and TgBack
- INT()-based heading normalization (avoids float division pitfall)
- Literal SINGLE values used instead of CONST names (workaround for CONST SINGLE module bug)

Known limitations:
- P96/RTG screens get native Amiga ratio (0.9375) instead of 1.0
  User should call TgSetRatio(1.0) for RTG screens until better detection is added
