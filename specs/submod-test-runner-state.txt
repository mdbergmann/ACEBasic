    - Turtle module uses COS/SIN which reference _MathTransBase
    - Compiler only calls _openmathtrans if the MAIN PROGRAM uses trig
    - When only the module uses trig, _MathTransBase stays NULL → crash
    - Fix: added `SINGLE _forceMathtrans = SIN(0.1)` to main program
  - This is a compiler limitation: modules that use trig need the main
    program to also reference trig to force _openmathtrans in startup
  - Filed as known compiler issue for future fix

## What Was Done

### Runner: submods/runner.rexx
- New ARexx test runner (~310 lines), modeled on verify/tests/runner.rexx
- Usage: `rx runner.rexx [submod|all]` from submods/ directory
- Three-state detection: PASS, FAIL (ASSERT FAILED or build error), SKIP (SKIPPED: in output)
- Source-level skip: scans first 10 lines for `REM $skip: reason`
- Auto-discovers submod directories with test_*.b files
- Calls `execute make` in each submod dir before running tests (if make file exists)
- EXIT 0 if no failures, EXIT 10 if any failures

### Make files (9 created)
- Each submod with tests gets a `make` AmigaDOS script
- Convention: `execute ACE:bin/bas -m <modulename>`
- Created for: amissl, dp-float, httpclient, iff, list, mui, sagasound, tcpclient, turtle
