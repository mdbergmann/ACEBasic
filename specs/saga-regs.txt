SAGA Chipset Register Map (SAGA-only extensions)
=================================================
Source: http://www.apollo-core.com/sagadoc/

This file lists registers that are new or extended in the Vampire SAGA
chipset. Classic OCS/ECS/AGA registers are omitted (see sagadoc for full list).


1. VIDEO CONTROL (Isabel)
--------------------------

  Address  Name        RW  Description
  -------  ----------  --  -------------------------------------------
  $DFF1E6  BPLHMOD     W   Chunky plane modulo
  $DFF1EC  BPLHPTH     W   Chunky framebuffer pointer (hi 16 bits)
  $DFF1EE  BPLHPTL     W   Chunky framebuffer pointer (lo 16 bits)
  $DFF1F4  GFXMODE     W   Pixel format + resolution

  GFXMODE word: high byte = resolution ID, low byte = pixel format.
  Setting $DFF1EC/$DFF1EE + $DFF1F4 displays a chunky framebuffer.

  Pixel formats:
    0x00  Planar     1-8 bpp    Classic Amiga bitplanes
    0x01  CLUT8      8 bpp      Chunky 256-color (palette indexed)
    0x02  RGB16      16 bpp     R5G6B5
    0x03  RGB15      16 bpp     0RRRRRGGGGGBBBBB
    0x04  RGB24      24 bpp     R8G8B8
    0x05  RGB32      32 bpp     A8R8G8B8
    0x06  YUV422     16 bpp     YUYVYUYV (video color space)

  Resolution IDs (V4):
    0x01  320x200     0x0C  800x600
    0x02  320x240     0x0D  1024x768
    0x03  320x256     0x0E  720x576
    0x04  640x400     0x0F  848x480
    0x05  640x480     0x10  640x200
    0x06  640x512     0x11  1920x1080
    0x07  960x540     0x12  1280x1024
    0x08  480x270     0x13  1280x800
    0x09  304x224     0x14  1440x900
    0x0A  1280x720    0x15  720x405
    0x0B  640x360

3. PiP (PICTURE-IN-PICTURE)
-----------------------------

  Address  Name          RW  Description
  -------  ------------  --  -------------------------------------------
  $DFF3D0  PipXStrt      W   PiP window X start position
  $DFF3D2  PipYStrt      W   PiP window Y start position
  $DFF3D4  PipXStop      W   PiP window X stop position
  $DFF3D6  PipYStop      W   PiP window Y stop position
  $DFF3D8  PipPtr        W   PiP framebuffer pointer (32-bit)
  $DFF3DC  PipFormat     W   PiP color format (8bit/16bit/15bit/YUV)
  $DFF3DE  PipModulo     W   PiP row modulo
  $DFF3E0  PipColorKey   W   PiP color key: 1000,RRRR,GGGG,BBBB
  $DFF3E2  PipDMARowLen  W   PiP DMA row length

  PiP is a hardware overlay - a second chunky playfield composited
  on top of the main display. It has its own framebuffer pointer,
  position, size, pixel format, palette, and color key transparency.

  PipFormat uses the same pixel format IDs as GFXMODE (section 1).
  PipColorKey bit 15 enables color keying (transparent color).


4. SPRITE (extended)
---------------------

  Address  Name        RW  Description
  -------  ----------  --  -------------------------------------------
  $DFF1D0  SPRHSTRT    W   SAGA Sprite X position
  $DFF1D2  SPRHSTOP    W   SAGA Sprite Y position
  $DFF1E8  SPRHPTH     W   SAGA sprite pointer (high 5 bits)
  $DFF1EA  SPRHPTL     W   SAGA sprite pointer (low 15 bits)
  $DFF3A2  Sprite Col1 W   Sprite color 1 RGB (12-bit, bits 11..0)
  $DFF3A4  Sprite Col2 W   Sprite color 2 RGB (12-bit, bits 11..0)
  $DFF3A6  Sprite Col3 W   Sprite color 3 RGB (12-bit, bits 11..0)

  Per-sprite collision detection (SAGA-only):
  $DFF230  clxdat0     R   Sprite 0 detailed collision
  $DFF232  clxdat1     R   Sprite 1 detailed collision
  $DFF234  clxdat2     R   Sprite 2 detailed collision
  $DFF236  clxdat3     R   Sprite 3 detailed collision
  $DFF238  clxdat4     R   Sprite 4 detailed collision
  $DFF23A  clxdat5     R   Sprite 5 detailed collision
  $DFF23C  clxdat6     R   Sprite 6 detailed collision
  $DFF23E  clxdat7     R   Sprite 7 detailed collision

  Classic sprites (SPR0-SPR7) at $DFF120-$DFF17E also work on SAGA.

7. MAGGIE 3D (texture mapping unit)
-------------------------------------

  Address  Name          RW  Description
  -------  ------------  --  -------------------------------------------
  $DFF250  TEXTPT        W   Texture source address
  $DFF254  TEXDPT        W   Destination screen address
  $DFF258  TEXZPT        W   3D Z-buffer address
  $DFF25E  TEXSTRT       W   Start + length (bit15=continue, bits10..0=pixels)
  $DFF260  TEXMIP        W   Texture size (bits3..0: $A=1024...$5=32),
                              bit4=auto mipmap mode
  $DFF262  TEXMODE       W   Texture mode flags:
                              bit0=bilinear, bit1=use zbuffer,
                              bit2=16bit output, bit3=inhibit zbuf write,
                              bit4=24bit output, bit5=quadratic mode,
                              bits7-6=blend (00=copy, 01=add, 10=mul)
  $DFF266  TEXDMOD       W   Destination step/modulo
  $DFF268  TEXddUU       W   Quadratic delta-delta U
  $DFF26C  TEXddVV       W   Quadratic delta-delta V
  $DFF270  TEXUUuuuu     W   3D 24-bit U coordinate
  $DFF274  TEXVVvvvv     W   3D 24-bit V coordinate
  $DFF278  TEXdUUuuuu    W   3D 24-bit delta U
  $DFF27C  TEXdVVvvvv    W   3D 24-bit delta V
  $DFF280  TEXLight      W   Light level
  $DFF282  TEXdLight     W   Delta light level
  $DFF284  TEXLightcolor W   Light color
  $DFF288  TEXZZzz       W   3D 32-bit Z value
  $DFF28C  TEXdZZzz      W   3D 32-bit delta Z


8. AUDIO (Arne/SagaSound, 16 channels)
----------------------------------------

  Channel N base = $DFF400 + (N * $10),  N = 0..15

  Offset  Size   Name       Description
  ------  -----  ---------  -------------------------------------------
  +$00    LONG   AUD_PTR    Sample address (32-bit pointer)
  +$04    LONG   AUD_LEN    Sample length (32-bit)
  +$08    WORD   AUD_VOL    Volume: bits 15-8 = left, bits 7-0 = right
  +$0A    WORD   AUD_CTRL   Mode: bit2=stereo, bit1=oneshot, bit0=16bit
  +$0C    WORD   AUD_PER    Period (PAL_CLOCK / sample_rate)

  DMA control:
    Channels 0-3:   $DFF096 (DMACON)  / $DFF002 (DMACONR)
    Channels 4-15:  $DFF296 (DMACON2) / $DFF202 (DMACON2R)
