  Header: include/submods/HTTPClient.h updated (HttpReadBody 4->3 params)
  Step 2.1 - Data Structures + Internal Helpers:

  Step 2.2 - Low-level API:
    - HttpSetHeader: case-insensitive header storage

    - HttpGetResponseHeader: case-insensitive header lookup
    - HttpReadBody: drains read buffer leftovers then recv, respects Content-Length/close modes
  Step 2.3 - High-level API:
    - HttpGet: URL parse, open, send GET, read status+body, return status code
    - HttpHead: URL parse, open, send HEAD, read status, return status code
